# 🤖 NLP AI Chatbot

An interactive AI Chatbot developed using **Python and Natural Language Processing (NLP)** techniques. The chatbot processes user input and provides responses using NLP concepts and text-processing methods.

## 🚀 Features
- Tokenization
- Stemming and Lemmatization
- Part-of-Speech (POS) Tagging
- Named Entity Recognition (NER)
- TF-IDF
- N-gram Analysis
- Text Processing
- Interactive Chat Interface
- Basic Human-like Conversations

## 🛠️ Technologies Used
- Python
- NLTK
- Streamlit
- Natural Language Processing

## 🎯 Objective
To demonstrate how NLP techniques can be used to process human language and develop an interactive chatbot that simulates basic human-like conversations.

## 👨‍💻 Project Type
Academic Team Project
